### 词汇叠加规则

单个 A 级词汇不构成侮辱，但叠加其他因素时侮辱性可能升级：

| 叠加方式 | 示例 | 结果 |
|---------|------|------|
| A + A | 「渣男，避雷」 | 仍为 A 级 |
| A + C | 「渣男，人渣」 | 升级为 C 级 |
| A + D | 「渣男，傻X」 | 升级为 D 级 |
| A + 隐私信息 | 「渣男」+ 附照片/手机号 | A 级语言 + 隐私侵权（数罪并罚） |
| A + 大规模传播 | 「渣男」+ 微博热搜亿级阅读 | 语言 A 级但传播系数极高 |

## 二、事实陈述 vs 主观评价判断规则

### 核心区分标准

- **事实陈述** = 可被证实或证伪的客观描述（「他偷了我的钱」「他是诈骗犯」）
- **主观评价** = 个人的感受和判断（「我觉得他的服务很差」「我的体验不好」）
- **事实+评价混合** = 需要分别审查每一部分

### 判断流程

```
内容 → 逐句拆分
  ├─ 这句话是事实陈述吗？
  │    ├─ 是 → 有证据吗？
  │    │    ├─ 有证据 → 安全（但仍需检查是否构成隐私泄露）
  │    │    └─ 无证据 → 诽谤风险
  │    └─ 否 → 这是主观评价吗？
  │         ├─ 是 → 用语是否侮辱？
  │         │    ├─ A/B级 → 一般安全
  │         │    └─ C/D级 → 侮辱风险
  │         └─ 混合 → 拆开分别判断
```

### 典型例子对照

| 原文 | 拆解 | 风险 |
|------|------|------|
| 「他偷了我的钱」 | 事实陈述（可证伪） | 无证据=诽谤 |
| 「我觉得他偷了我的钱」 | 主观感受+事实暗示 | 风险较低但非零 |
| 「他这个骗子偷了我的钱」 | 「骗子」(B级) + 「偷钱」(事实) | 需证据+语言注意 |
| 「我的消费体验很差」 | 纯主观评价 | 安全 |
| 「他是个诈骗犯」 | 事实陈述（法律定性） | **严重**：无证据=诽谤，且「诈骗犯」是刑法概念 |
| 「他和多个女生保持关系」 | 事实陈述 | 需证据，否则诽谤 |
| 「据我所知，他和多个女生保持关系」 | 「据我所知」缓冲+事实 | 风险降低但仍需合理依据 |
| 「我觉得他这个人不靠谱」 | 纯主观评价 | 安全 |

### 「据我所知」「我认为」「在我看来」的缓冲作用

- 加上这些前缀可以将事实陈述转化为**带保留的意见表达**
- 但缓冲有限：
  - 「我认为他是诈骗犯」→ 仍是严重指控，缓冲有限
  - 「在我看来他的服务不好」→ 有效缓冲，风险低
  - 「据我所知他吸毒」→ 严重指控，缓冲几乎无效
- **规则：** 指控越严重，缓冲前缀的作用越弱

## 三、隐私边界规则

### 「说的是事实」不是完整抗辩

法院在多个案例中明确：即使你说的内容属实，公开他人的个人信息仍可能构成隐私侵权。

| 情况 | 是否构成隐私侵权 | 说明 |
|------|-----------------|------|
| 对方确实欠你钱，你公开他的身份证号 | 是 | 「事实」不等于你可以公开身份证号 |
| 对方确实出轨，你公开他的手机号 | 是 | 「事实」不等于你可以公开手机号 |
| 照片是对方自己发过的，你转发到辱骂语境 | 是 | 转发到不同语境仍构成侵权 |
| 信息在网上能搜到，你集中整理发布 | 可能 | 集中整理+曝光语境可能构成侵权 |
| 对方是商家，你公开商家地址和店名 | 一般不构成 | 商家信息属于公开经营信息 |
| 对方是商家老板，你公开老板身份证号 | 构成 | 自然人隐私 ≠ 商家经营信息 |

### 可公开 vs 不可公开的边界

| 可以说 | 不可以说 |
|--------|---------|
| 「某某商家服务态度差」 | 「他的手机号是 138XXXX」 |
| 「我在 XX 店消费体验不好」 | 「他的身份证号是 XXXX」 |
| 「我和 XX 发生了纠纷」 | 「他住在 XX 小区 X 栋 X 号」 |
| 「这家店卖的东西有问题」 | 「老板叫 XXX，照片如下」 |
| 「XX 公司存在 XX 问题」 | 「XX 的家庭住址是...」 |
| 消费者差评+商家公开信息 | 消费者差评+老板个人手机号 |

### 隐私信息类型与风险等级

| 信息类型 | 风险等级 | 说明 |
|---------|---------|------|
| 身份证号 | 极高 | 受《个人信息保护法》严格保护，即使对方犯罪也不可公开 |
| 手机号 | 高 | 直接联系信息，属于隐私 |
| 微信号 | 高 | 同上 |
| 真实姓名 + 照片 | 高 | 可识别特定自然人 |
| 家庭住址 | 高 | 可定位物理位置 |
| 工作单位 + 职务 | 中高 | 可定位社会关系 |
| 真实姓名（无照片） | 中 | 需结合其他信息判断可识别性 |
| 照片（未打码/打码不足） | 高 | 肖像权 + 可识别性 |
| 学校/班级 | 中 | 可定位社会关系 |
| 聊天记录截图（含对方头像/昵称） | 中 | 取决于是否可识别 |
| 社交媒体账号名 | 中低 | 取决于账号是否实名 |

## 四、转发/转述的责任

### 转发不等于免责

| 行为 | 是否可能承担责任 | 说明 |
|------|-----------------|------|
| 转发他人发布的侵权内容 | 是 | 可能承担连带责任 |
| 「听说 XXX 是...」 | 是 | 转述诽谤同样可能构成侵权 |
| 截图转发到群聊 | 是 | 截图本身可能构成二次传播 |
| 「群里有人说了 XX」 | 视情况 | 引用+传播=可能扩大损害 |
| 点赞侵权内容 | 视情况 | 北京三中院案例：点赞的定性存在争议 |
| 评论/跟帖 | 视情况 | 评论本身如果构成侮辱/诽谤则独立构成侵权 |

### 转发责任判断因素

1. **转发者是否知道或应当知道内容不实** — 知道仍转发，过错更重
2. **转发者是否添加了自己的评论** — 添加侮辱性评论=独立侵权
3. **转发范围** — 私聊转发 vs 公开平台转发，后果不同
4. **是否是公共利益的新闻报道** — 新闻媒体转载有一定豁免空间，普通人没有
5. **是否进行了核实** — 未经核实的转发过错更重

## 五、特别容易踩坑的表达

以下表达在日常生活中常见，但在法律上风险较高：

| 表达 | 日常理解 | 法律风险 | 安全替代 |
|------|---------|---------|---------|
| 「他是骗子/诈骗犯」 | 表达不满 | 无证据=诽谤（刑法概念） | 「我觉得被欺骗了」/「我的体验和承诺不符」 |
| 「他出轨了」 | 陈述事实 | 无证据=诽谤 | 「据我了解，他和多人保持关系」(需有依据) |
| 「他吸毒」 | 陈述事实 | 无证据=严重诽谤 | — (不建议在无证据时公开指控) |
| 「他是小三」 | 道德评价 | 无证据=诽谤+隐私 | — (不建议公开指控) |
| 曝光聊天记录 | 维权 | 隐私侵权 | 向法院提交作为证据（非公开传播） |
| 曝光对方照片 | 让人认识他 | 肖像权+隐私侵权 | 描述行为而非曝光人脸 |
| 「大家一起转发」 | 扩大影响 | 主动引导传播=加重情节 | 不引导传播，通过法律途径 |
| 发到多个平台 | 让更多人知道 | 跨平台发布=加重系数x3 | 选择一个渠道，合法表达 |

## 六、「事出有因」语境下的词汇重新分级

> 本表适用于对方有过错在先的场景（恋爱背叛、消费欺诈、暴力受害等）。同一词汇在「陌生人无端攻击」和「受害者愤怒表达」两种语境下，法院的容忍度不同。
>
> **来源：** 多个法院在名誉权案件中考量「事出有因」「被告系因对方过错而情绪激动」等背景因素 [platform_found]。
>
> **注意：** 降级仅影响侮辱性程度认定，不影响隐私侵权和诽谤的判断。D 级（粗口/谩骂）用语在所有语境下均不降级。

### 降级规则

| 通用场景评级 | 恋爱纠纷语境调整 | 条件 |
|------------|----------------|------|
| A 级 | 不变（已经安全） | — |
| B 级 | 不变（本就视语境而定） | — |
| C 级 | **可降至 B 级** | 需同时满足：① 双方存在特定关系（恋爱/消费/职场等）；② 对方存在 III 级以上过错；③ 该词汇用于表达对过错行为的愤怒而非无端人身攻击 |
| D 级 | **不降级** | 粗俗谩骂在任何语境下均构成侮辱（指导案例143号 [verified]） |

### 「事出有因」词汇对照表

| 词汇/表达 | 通用场景 | 事出有因语境 | 降级条件 | 参考依据 |
|----------|---------|------------|---------|---------|
| 「渣男/渣女」 | A-安全 | A-安全 | 不需要额外条件 | 多案一致 [platform_found] |
| 「不靠谱」「骗子」（指对方欺骗感情） | B-注意 | B-注意 | 需有证据支撑 | — |
| 「出轨惯犯」「多次出轨」 | B-注意 | B-注意（但有据则不构成诽谤） | 需有证据证明事实 | 事实有据=不构成诽谤 [platform_found] |
| 「不负责任」「令人失望」 | B-注意 | A-安全 | 对方有过错时视为正常情绪表达 | [model_inference] |
| 「恶心」「感到恶心」 | B-注意 | A-B | 对行为的感受表达，非人身攻击 | [model_inference] |
| 「玩弄感情」「欺骗」 | B-C | B | 若有证据支撑事实，视为对行为的概括性评价 | [platform_found] |
| 「人渣」「不要脸」 | C-警告 | B-注意 | 对方 III 级以上过错时降级 | [model_inference] |
| 「无耻」 | C-警告 | B-注意 | 同上 | [model_inference] |
| 「垃圾」（指人） | C-警告 | B-注意 | 同上 | [model_inference] |
| 「NPD」「自恋型人格」（非专业诊断） | B-C | B | 视为主观评价，非专业诊断不构成事实陈述 | [model_inference] |
| 「杀人诛心」 | C-警告 | B-注意 | 对行为的情感评价 | [model_inference] |
| 将对方比作已定罪的犯罪者 | C-D | C-警告（不降至B） | 即使出轨属实，夸大类比仍有风险 | [platform_found] |
| 「傻X」「臭傻X」 | D-危险 | D-危险（不降级） | 粗俗谩骂不因语境改变 | 指导案例143号 [verified] |
| 「畜生」「去死」 | D-危险 | D-危险（不降级） | 同上 | [platform_found] |
| 性侮辱/粗口 | D-危险 | D-危险（不降级） | 同上 | [platform_found] |

### 降级的法律逻辑

法院在「事出有因」案件中考量以下因素后可能降低侮辱性认定：

1. **「事出有因」**：非无端攻击，而是对对方过错的反应 [platform_found]
2. **情绪状态**：发现背叛后处于应激状态，措辞过激可理解 [model_inference]
3. **对方过错程度**：过错越严重，对过激措辞的容忍度越高 [model_inference]
4. **传播范围与持续性**：降级只影响语言评级，如果跨平台多账号持续发布，仍属加重情节 [platform_found]

### 不降级的红线

以下情况即使满足「事出有因」条件也**不降级**：

- 使用粗口/脏话（D 级）
- 威胁性言论（「让你身败名裂」等）
- 将纠纷扩展到对方家人
- 在公共话题下植入个人纠纷

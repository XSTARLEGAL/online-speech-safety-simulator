# 平台风险评估矩阵与赔偿预测

本文件为 `online-argument-compliance-checker` 的参考文件，提供平台分级、传播系数、加重/减责系数、赔偿预估公式和刑事门槛。

---

## 一、平台传播力五级分级

| 梯队 | 平台/场景 | 典型可见人数 | 传播特点 | 典型民事赔偿范围 | 代表案例 |
|------|---------|-------------|---------|-----------------|---------|
| T1-低 | 私聊、<20人小群 | <20人 | 封闭传播，极有限 | 0-500元或驳回 | 杨林森案：朋友圈10人可见，仅判删除 [platform_found] |
| T2-中 | 朋友圈、20-100人群 | 20-100人 | 半封闭，中等范围 | 500-3000元 | 范某某案：朋友圈持续辱骂邻居，判道歉 [platform_found] |
| T3-高 | 100-500人大群、业主群、班级群 | 100-500人 | 半公开，较大范围 | 1000-5000元 | 指导案例143号：345人+123人业主群，判3000+2000元 [verified] |
| T4-很高 | 微博(未热搜)、抖音、小红书、贴吧、知乎 | 数百-数万 | 公开传播，可能扩散 | 2000-20000元 | 马某案：微博热搜#1，900+转发16万赞，判6000元 [platform_found] |
| T5-极高 | 微博热搜、亿级阅读、万级转发、跨平台传播 | 万级以上 | 大规模传播，极难控制 | 10000-53000元 | 重庆钱某案：1.3亿阅读，判22800元 [platform_found]；李彬案：贴吧40+帖持续1年，判53000元 [platform_found] |

**关键裁判规则：** 不特定关系人组成的微信群具有公共空间属性（指导案例143号 [verified]）。即使朋友圈「仅好友可见」，在共同亲友圈子中仍可导致社会评价降低（临沂范某某案 [platform_found]）。

## 二、传播系数

用于赔偿预估乘法模型：

| 可见人数 | 传播系数 | 说明 |
|---------|---------|------|
| <20人 | x0.2 | 传播极有限，赔偿低或驳回 |
| 20-100人 | x0.5 | 半封闭传播，中等风险 |
| 100-500人 | x1.0 | 基准线，视为公开传播 |
| 500-10000人 | x2.0 | 较大规模传播 |
| >10000人 | x5.0 | 大规模传播，赔偿显著提高 |

## 三、加重系数

| 因素 | 系数 | 说明 | 参考依据 |
|------|------|------|---------|
| 跨平台发布（3个及以上） | x3 | 注册多个平台发布相同内容 | 多案：跨平台发布认定为主观恶意 [platform_found] |
| 持续时间长（1个月以上） | x3 | 多次反复发布，非一次冲动 | 多案：贴吧持续1年发布40+帖 [platform_found] |
| @明星/大V扩大传播 | x5 | 主动引导舆论，主观恶意大 | 多案：@明星引发热搜亿级传播 [platform_found] |
| 附照片/身份证 | x2 | 加重情节，构成肖像权+隐私侵权 | 多案一致 [platform_found] |
| 违反和解协议再发 | x5 | 主观恶意极大，屡教不改 | 多案：违反和解协议继续发帖 [platform_found] |
| 第三方身份发布 | x2 | 非当事人介入他人纠纷 | 多案：第三人公布他人私密细节 [platform_found] |
| 公开他人家庭信息/工作单位 | x2 | 扩大隐私侵害范围 | 多案：公开父母工作单位 [platform_found] |
| 多账号发布 | x2 | 同一人用多个账号发布 | 多案一致 [platform_found] |

**叠加规则：** 多个加重因素同时存在时取最高值乘以1.5，不做简单连乘（避免系数爆炸）。

## 四、减责系数

| 因素 | 系数 | 说明 | 参考依据 |
|------|------|------|---------|
| 对方有重大过错（犯罪/暴力/重大欺骗） | /10 | 对方行为本身构成违法 | 多案「事出有因」重大减责 [platform_found] |
| 对方有严重过错（欺骗/隐瞒/脚踏两只船）+ 你方有强证据（录音/书面承认） | /8 | 对方承认行为事实+你方证据充分 | 民法典第1173条 + 事实有据瓦解诽谤 [verified] |
| 对方有严重过错 + 你方有中证据（聊天记录/照片） | /5 | 对方行为存在道德/法律瑕疵 | 多案「事出有因」减责 [platform_found] |
| 对方有明显过错（不忠/违约/侵权在先） | /5 | 对方行为存在道德/法律瑕疵 | 多案「事出有因」减责 [platform_found] |
| 「事出有因」（有合理起因） | /3 | 非无端攻击，有纠纷背景 | 多案一致 [platform_found] |
| 及时删除（48小时内） | /2 | 体现悔意，限制传播 | 高某案：24小时内删除+注销 [platform_found] |
| 传播范围极小（有数据佐证） | /3 | 如阅读量<100 | 孔德佳案：阅读量极低 [platform_found] |
| 主动道歉/和解 | /2 | 积极补救 | [model_inference] |
| 对方已社会性死亡（无更多损害） | /2 | 损害后果有限 | [model_inference] |

**叠加规则：** 取最适用的一个减责系数，不做连除。但「对方重大过错」+「及时删除」可叠加为 /15。

## 五、赔偿预估公式

```
预估赔偿 = 基础等级赔偿 × 传播系数 × 加重系数 / 减责系数
```

### 基础等级

| 等级 | 内容特征 | 基础赔偿范围 |
|------|---------|-------------|
| 1级 | 仅 A 级网络用语（「渣男」「避雷」） | 0-500元 |
| 2级 | A+B 级语言 + 带情绪的中性陈述 | 500-2000元 |
| 3级 | C 级贬损性人格评价（「人渣」「不要脸」） | 1000-5000元 |
| 4级 | D 级谩骂 或 严重事实指控无证据（吸毒/犯罪） | 3000-10000元 |
| 5级 | 关联死亡/极端事件 + D 级语言 + 大规模传播 | 10000-53000元 |

### 预估示例

**场景 A：** 在500人业主群里骂邻居「不要脸的人渣」
- 基础等级：3级（C级语言）= 1000-5000元
- 传播系数：T3 = x1.0
- 加重系数：无 = x1.0
- 减责系数：事出有因（邻里纠纷）= /3
- **预估：300-1700元**

**场景 B：** 在微博发前老板照片+姓名，骂「傻X骗子，压榨员工」
- 基础等级：4级（D级+事实指控）= 3000-10000元
- 传播系数：T4 = x2.0
- 加重系数：附照片 = x2
- 减责系数：对方可能有过错 = /5
- **预估：2400-8000元**

**场景 C：** 在小红书发消费差评「这家店服务态度很差，避雷」
- 基础等级：1级（A级语言）= 0-500元
- 传播系数：T4 = x2.0（但消费者投诉有保护）
- 特殊场景减免：消费者差评受保护
- **预估：0元（不构成侵权）**

**场景 D（对方过错+有证据）：** 发现对方欺骗后，在多个平台发帖指责对方，使用了贬损性词汇（C级），公开了对方微信号和学校信息
- 基础等级：3级（C级语言+隐私泄露）= 1000-5000元
- 传播系数：T4 = x2.0
- 加重系数：跨平台（3个以上）= x3
- 减责系数：对方严重过错 + 有录音证据 = /8
- **预估：(1000-5000) × 2.0 × 3 / 8 = 750-3750元**
- 注：隐私泄露部分不减免，但整体赔偿因对方过错大幅降低

**场景 E（对方过错+无证据+粗口）：** 同场景D，但无任何证据证明对方过错，且使用了D级粗口谩骂
- 基础等级：4级（D级语言+隐私泄露）= 3000-10000元
- 传播系数：T4 = x2.0
- 加重系数：跨平台 = x3
- 减责系数：对方过错但无证据 = /3
- **预估：(3000-10000) × 2.0 × 3 / 3 = 6000-20000元**

## 六、刑事门槛速查

### 刑法第246条（侮辱罪/诽谤罪）

「情节严重」标准（满足**任一**即达到刑事立案门槛）：

| 标准 | 阈值 | 说明 |
|------|------|------|
| 点击量 | 同一诽谤信息实际被点击 **5000次以上** | 最高法、最高检《关于办理利用信息网络实施诽谤等刑事案件适用法律若干问题的解释》 [verified] |
| 转发量 | 同一诽谤信息实际被转发 **500次以上** | 同上 [verified] |
| 严重后果 | 造成被害人或其近亲属 **精神失常、自残、自杀** 等 | [verified] |
| 屡犯 | 两年内因诽谤受过行政处罚，又诽谤他人 | [verified] |
| 其他 | 其他情节严重的情形 | 兜底条款 [verified] |

**最高刑期：** 三年有期徒刑、拘役、管制或者剥夺政治权利。

**告诉才处理原则：** 侮辱罪/诽谤罪一般属于自诉案件（被害人自己起诉），但「严重危害社会秩序和国家利益」的除外。

### 刑事风险实际评估

| 平台 | 达到5000点击/500转发的可能性 | 说明 |
|------|---------------------------|------|
| 私聊/小群 | 极低 | 封闭传播，几乎不可能达到 |
| 朋友圈 | 低 | 取决于好友数量和传播 |
| 大群/业主群 | 中低 | 可能被截图外传 |
| 微博（未热搜） | 中 | 有一定粉丝即可达到 |
| 抖音/小红书 | 中高 | 算法推荐容易推高数据 |
| 微博热搜 | 极高 | 几乎必然超过 |

### 治安管理处罚法第42条

| 行为 | 处罚 |
|------|------|
| 公然侮辱他人 | 5日以下拘留或500元以下罚款 |
| 捏造事实诽谤他人 | 5日以下拘留或500元以下罚款 |
| 情节较重 | 5-10日拘留，可并处500元以下罚款 |

**注意：** 治安处罚是行政处罚，不需要达到刑事门槛。只要「公然侮辱」或「捏造事实诽谤」即可触发，门槛比刑事低很多。

## 七、互骂场景的赔偿规则

双方互相在网上攻击的，法院通常的裁判模式：

| 规则 | 说明 | 参考依据 |
|------|------|---------|
| 双方均构成侵权 | 不存在「他先骂的所以我骂回去就合法」 | 北京互联网法院互骂案 [platform_found] |
| 各自向对方道歉 | 在侵权发生的同一平台/群内道歉 | 同上 |
| 各自赔偿对方 | 律师费互赔，精神损害通常互抵 | 福州长乐互骂案 [platform_found] |
| 精神损害通常不支持 | 双方均有过错，法院认定不构成「严重精神损害」 | 多案一致 [platform_found] |
| 正确做法 | 保留对方侵权证据，走法律途径，不要对骂 | — |

# 网络言论侵权案例库（按场景分类）

本文件汇总网络侮辱、诽谤、挂人、曝光等场景的裁判案例，供 `online-argument-compliance-checker` 引用。来源：Alpha 案例库 438 份判决书 + 网络公开裁判文书。

---

## 一、消费者差评/投诉类

### 案例 1.1：微信群差评被诉——不构成侵权
- **案号**：山东烟台牟平法院
- **场景**：消费者在微信群内发表产品差评
- **法院认定**：被告言论基于自身消费经历，表达主观感受及个人体验，并非凭空捏造，评价内容未达到侮辱、诽谤程度。**驳回原告诉请**
- **裁判规则**：消费者对产品/服务的批评、评论，不应当认定为侵害名誉权。但借机诽谤、诋毁的除外 [platform_found]
- **来源**：https://www.sdcourt.gov.cn/ytmpqfy/389951/389952/21231700/index.html

### 案例 1.2：差评+侮辱性语言——构成侵权
- **场景**：消费者差评中加入「人渣」「骗子」等侮辱性语言
- **法院认定**：基于真实体验的差评受保护，但加入侮辱性语言超出合理批评范围，构成侵权
- **裁判规则**：差评安全线 = 真实体验 + 中性语言 + 商家公开信息；越过安全线 = 侮辱/捏造/公开老板个人隐私 [platform_found]

## 二、微信群骂人/挂人类

### 案例 2.1：最高法指导案例143号——业主群侮辱构成侵权
- **案号**：(2017)京0113民初5491号 → (2018)京03民终725号
- **法院**：北京顺义法院 → 北京三中院
- **场景**：赵敏因美容纠纷，在两个小区业主群（345人+123人）中使用「傻X」「臭傻X」「精神分裂」「装疯卖傻」等侮辱性言论，配黄晓兰照片，散布「美容师不正规」「讹诈客户」「破仪器」等贬损言辞
- **判决**：张贴致歉声明7天 + 赔偿公司经济损失3000元 + 精神损害抚慰金2000元
- **裁判规则**：**不特定关系人组成的微信群具有公共空间属性** [verified]
- **来源**：最高法指导案例143号

### 案例 2.2：微信群公布他人电话+侮辱——构成侵权
- **案号**：(2020)鲁0523民初1962号
- **法院**：山东广饶县法院
- **场景**：李某因投资损失，在「县局已报案群」（245人）和「FINUK客户群」（329人）中发布侮辱性言论+公布钟某电话及父亲姓名职务
- **判决**：删除不当言论 + 群内道歉声明（至少7天）+ 精神损害抚慰金1000元
- **裁判规则**：公布他人电话+亲属信息 = 隐私侵权叠加名誉侵权 [platform_found]

### 案例 2.3：微信群用小号造谣——构成侵权
- **法院**：河南沈丘法院
- **场景**：王某因装修纠纷，用大号+小号在近500人业主群内一唱一和，散布李某房屋为法拍房、李某骗钱的消息
- **判决**：群内公开道歉 + 精神损失费1000元
- **裁判规则**：使用小号自导自演 = 主观恶意明显，加重情节 [platform_found]

### 案例 2.4：村集体微信群诬陷偷窃——构成侵权
- **法院**：河南浚县法院
- **场景**：在公安机关未查明案件事实的情况下，被告在村集体微信群（300余人）中发布「见利忘义猪狗不如」「贱妇」「人渣」「三只手」等侮辱性言论
- **判决**：群内连续三日书面+语音道歉 + 精神损害抚慰金
- **裁判规则**：未经公安认定就在群里定性他人行为 = 主观过错明显 [platform_found]

### 案例 2.5：业主群质疑工作能力——不构成侵权
- **法院**：深圳福田区法院（2025年）
- **场景**：业主在近500人业主群质疑业委会秘书「未经公示程序入职」「工作能力不足」
- **判决**：**驳回全部诉请**。言论围绕入职程序合规性及工作表现，非为丑化或损害名誉而捏造
- **裁判规则**：基于公共事务的合理质疑，即使措辞不当，未达到侮辱诽谤程度的不构成侵权 [platform_found]

## 三、朋友圈骂人/挂人类

### 案例 3.1：朋友圈连发40条辱骂——构成侵权（高额赔偿）
- **法院**：广州南沙法院 → 广州中院（2024年，二审维持）
- **场景**：芳芳怀疑前男友与小丽有不正当关系，在朋友圈发布40条侮辱内容+小丽与男性合照+手机号截图。微信好友中有集团大量领导同事。小丽因此抑郁就医
- **判决**：删除40条 + 朋友圈道歉10天 + **精神损害赔偿20000元**
- **裁判规则**：持续发布+附带个人照片信息+导致抑郁 = 高额赔偿 [platform_found]

### 案例 3.2：朋友圈连发三条辱骂前同事——构成侵权
- **法院**：郑州中院（2024年）
- **场景**：郭某某因离职纠纷，在朋友圈连发三条用侮辱性语言标注前同事姓名的内容
- **判决**：朋友圈连续三天公开道歉 + 精神损害抚慰金1000元
- **裁判规则**：「仅好友可见」不构成免责，共同好友圈足以导致社会评价降低 [platform_found]

### 案例 3.3：朋友圈持续骂邻居一年半——构成侵权
- **法院**：临沂法院
- **场景**：范某某因琐事在朋友圈持续辱骂邻居王某某（2021.3-2022.8）
- **判决**：删除内容 + 朋友圈道歉3天。精神损害赔偿不支持（未提交证据）
- **裁判规则**：「事出有因」可减责，但持续时间长仍构成侵权；精神赔偿需举证 [platform_found]

### 案例 3.4：朋友圈挂前老板照片辱骂——构成侵权
- **法院**：北京四中院（2023年）
- **场景**：小李离职后将公司法定代表人小赵的照片+姓名+公司名发到朋友圈辱骂
- **判决**：公开致歉 + 精神损害赔偿2000元 + 其他经济损失
- **裁判规则**：**名誉权是否被侵害不取决于言论是否被认识受害者的人所知悉**，只要为受害者以外的人知悉即可能构成侵权 [platform_found]

### 案例 3.5：温州朋友圈发700好友可见辱骂——构成侵权
- **法院**：温州瓯海法院（2020年）
- **场景**：李某因业务纠纷，在朋友圈（约700好友）发布侮辱性语言+对方照片
- **判决**：不屏蔽任何人公开发布朋友圈道歉（至少10日）
- **裁判规则**：朋友圈700好友可见 + 附照片 = 传播范围足够导致评价降低 [platform_found]

## 四、微信群/平台互骂类

### 案例 4.1：房源群500人互骂——双方均构成侵权
- **法院**：北京互联网法院（2024年）
- **场景**：王某与和某因房屋租赁纠纷，在近500人房源信息群中互相攻击。王某发布对方真实姓名+私聊记录，称其「压榨租户」；和某也发布贬损性言论
- **判决**：双方各自在群内公开道歉。精神损害赔偿均不支持
- **裁判规则**：**互骂互赔，「他先骂的」不构成免责** [platform_found]

### 案例 4.2：21人微信群互骂近一年——双方均构成侵权
- **法院**：福州长乐法院 → 福州中院（2025年，二审维持）
- **场景**：陈某甲与陈某乙因民间互助会费纠纷，在21人微信群中持续互骂（2023.12-2024.10）
- **判决**：群内致歉声明保留10日 + 互赔律师费3750元。精神损害均不支持
- **裁判规则**：即使小群互骂也各自担责；精神赔偿双方均不支持 [platform_found]

## 五、邻里纠纷类

### 案例 5.1：小区微信群散布邻居生活隐私——构成侵权
- **法院**：上海闵行法院
- **场景**：龚某在成员百余人的「互帮互助群」和「邻里互助群」中，发布针对邻居王某某夫妇家庭生活、子女教育及道德品行方面的言论
- **判决**：群内书面公开道歉 + 精神损害抚慰金1000元。群解散后，执行法官陪同被告逐户上门说明情况
- **裁判规则**：邻里纠纷在群内散布他人家庭生活细节 = 隐私+名誉双重侵权 [platform_found]

### 案例 5.2：村委会通知群发视频攻击邻居——肖像权侵权
- **案号**：(2025)京04民终1276号
- **法院**：北京四中院
- **场景**：王某乙以邻居垒墙影响出行为由，多次在村委会通知群发布王某甲的视频和文字进行攻击
- **判决**：构成肖像权侵权，判赔礼道歉。但精神损害赔偿不支持（证据不足）
- **裁判规则**：邻里纠纷中未经同意发布他人视频 = 肖像权侵权；但精神损害需证明「严重」后果 [platform_found]

## 七、第三方传播/造谣类

### 案例 7.1：微信群误传「第三者」——构成侵权
- **法院**：上海奉贤法院
- **场景**：王某看到班级群中的非正常交往八卦，误将李某当成「第三者」，在近500人微信群发李某照片。后经确认李某与事件无关
- **判决**：朋友圈+公众号道歉3天 + 精神损害3000元 + 律师费4000元
- **裁判规则**：**未经核实就转发+配照片 = 主观过错**；即使后续澄清，损害已造成 [platform_found]

### 案例 7.2：使用微信小号造谣（案例2.3同）
- 沈丘法院：主观恶意明显，判1000元

- **案号**：(2022)渝01民终8643号
- **法院**：重庆一中院
- **场景**：孙某自杀后，赵某（孙某朋友）发10+微博称钱某「PUA渣男」，@明星引发热搜，1.3亿阅读。赵某系第三人（非恋爱关系当事人）

## 十一、赔偿金额速查（按严重程度排列）

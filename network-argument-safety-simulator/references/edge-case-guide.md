# 特殊场景处理指引

本文件为 `online-argument-compliance-checker` 的参考文件，提供消费者投诉、职场纠纷、邻里矛盾、举报吹哨、互骂场景的「能说/不能说」指引。

---

## 一、消费者投诉发帖

### 法律保护

- **消费者权益保护法第15条**：消费者享有对商品和服务进行监督的权利 [verified]
- 基于真实消费体验的差评受法律保护
- 但保护有边界：必须基于真实消费事实，不可使用侮辱性语言或捏造事实

### 安全线

| 可以说 | 不可以说 |
|--------|---------|
| 「这家店服务态度很差」 | 「这家店的老板是个骗子人渣」 |
| 「产品有质量问题，我的体验不好」 | 「这家店卖假货，老板去死」 |
| 「我不会再来消费了，避雷」 | 「老板电话 138XXXX，大家一起去找他」 |
| 「这是我真实的消费体验，仅供参考」 | 捏造从未发生的不实消费经历 |
| 「XX 店的 XX 产品存在 XX 问题（事实描述）」 | 「XX 店老板是诈骗犯」（无司法认定） |
| 「差评：物流慢、包装破损、客服不回复」 | 「差评：XX 店老板是 SB，全家不得好死」 |
| 「建议其他人购买前考虑清楚」 | 「大家一起去工商局举报这个黑店」(引导集体行动) |

### 关键裁判规则

1. **基于真实体验的消费评价，即使措辞尖锐，一般不构成侵权** [platform_found]
2. **但加入侮辱性语言或捏造事实，超出合理批评范围则构成侵权** [platform_found]
3. 差评 + 商家真实信息（如店名、地址）= 一般安全，属于合理消费评价 [model_inference]
4. 差评 + 老板个人信息（手机号、住址、身份证）= 超出合理范围，构成隐私侵权 [platform_found]
5. **同行恶意差评** = 不受消费者保护，构成不正当竞争或侵权 [model_inference]

### 消费者投诉的安全流程

```
发现问题 → 保留证据（小票/照片/聊天记录）
  → 先与商家沟通
  → 沟通不成 → 向 12315/平台投诉
  → 投诉无果 → 可以发差评（基于事实，中性语言）
  → 发差评后仍无法解决 → 考虑法律途径（小额诉讼）
  → 全程不发：侮辱性语言、对方个人信息、捏造事实
```

## 二、职场纠纷 / 劳动争议

### 员工在社交媒体发声

| 可以说 | 不可以说 |
|--------|---------|
| 「我在 XX 公司的劳动体验不好」 | 「XX 公司老板是傻X」 |
| 「公司存在加班问题（有据可查）」 | 「XX（具体姓名）是极品人渣」 |
| 「我已向劳动监察部门举报了 XX 公司」 | 公开同事的手机号/身份证号 |
| 对劳动仲裁结果的公开讨论（不涉密） | 泄露公司未公开的财务数据/商业秘密 |
| 「提醒求职者注意了解清楚再入职」 | 「XX 公司是传销/诈骗」（无证据） |

### 职场场景的三个法律维度

| 维度 | 保护 | 边界 |
|------|------|------|
| 举报权 | 宪法第41条赋予检举权 [verified] | 必须向有权机关举报，非直接上网曝光 |
| 言论自由 | 基于事实的劳动体验分享一般受保护 | 不可侮辱、不可泄露商业秘密 |
| 商业秘密 | — | 劳动合同/保密协议中的保密义务，违反可追责 |

### 前同事/前老板纠纷

- 批评前公司管理 = 一般安全（基于事实）
- 具名辱骂前老板 = 构成名誉侵权（北京四中院小李案：朋友圈挂前老板照片+姓名辱骂，判2000元精神赔偿 [platform_found]）
- 公开公司内部文件 = 可能违反保密协议 + 侵犯商业秘密
- **安全原则：** 说事不说人，说体验不说身份信息

## 三、邻里纠纷

### 常见场景

- 业主群中指责邻居噪音/漏水/占用公共空间
- 在群里公开对方的房号、姓名
- 因琐事在朋友圈辱骂邻居

### 关键规则

| 规则 | 说明 | 参考依据 |
|------|------|---------|
| 业主群 = 公共空间 | 100-500人的业主群视为公开传播 | 指导案例143号 [verified] |
| 事实+文明 = 安全 | 「X楼X号的住户，能否注意一下噪音」 | [model_inference] |
| 事实+侮辱 = 侵权 | 即使对方确实有错，用侮辱性语言仍构成侵权 | 临沂范某某案 [platform_found] |
| 互骂互赔 | 双方互相辱骂的，各自承担侵权责任 | 福州长乐互骂案 [platform_found] |

### 安全线

| 可以说 | 不可以说 |
|--------|---------|
| 「X 楼 X 号的住户，你家装修声音有点大，能不能注意一下时间」 | 「X 楼 X 号那个不要脸的天天吵死人」 |
| 「我想通过物业协调解决漏水问题」 | 「那个恶人偷水漏到我家」 |
| 陈述客观事实（时间、分贝、持续多久） | 侮辱性人身攻击 |
| 「请问谁家有类似情况，可以一起跟物业反映」 | 在群里公布对方手机号/工作单位 |

### 邻里纠纷的正确处理

```
发现问题 → 记录证据（拍照/录音/记时间）
  → 先友好沟通
  → 沟通不成 → 找物业/居委会调解
  → 调解不成 → 报警（噪音/漏水等）
  → 仍无法解决 → 民事诉讼
  → 全程不在群里/朋友圈辱骂
```

## 四、举报 / 吹哨 / 公共利益

### 法律保护

- **宪法第41条**：公民对国家机关和国家工作人员有批评、建议、申诉、控告、检举的权利 [verified]
- 举报违法行为受法律保护
- 但保护条件：**不得捏造或歪曲事实进行诬告陷害**

### 安全线

| 可以说 | 不可以说 |
|--------|---------|
| 向纪检/监察/主管部门**实名举报** | 在网上公开被举报人的个人信息 |
| 「我了解到 XX 可能存在违规行为，已向 XX 部门举报」 | 「XX 是贪官/罪犯」（未经司法认定） |
| 提供有证据支撑的事实材料 | 捏造或夸大事实 |
| 通过正规渠道提交举报材料 | 把举报材料发到网上「让大家都知道」 |

### 举报 vs 网上曝光的关键区别

| 维度 | 举报（受保护） | 网上曝光（高风险） |
|------|--------------|------------------|
| 对象 | 有权机关 | 不特定公众 |
| 方式 | 实名/匿名提交 | 公开发布 |
| 内容 | 有证据的事实材料 | 可能包含他人隐私 |
| 法律后果 | 受保护（不得捏造） | 可能构成名誉/隐私侵权 |
| 效果 | 启动调查程序 | 可能引发网暴/二次侵权 |

### 重要提醒

1. **举报应当向有权机关提出**，而非直接上网曝光
2. 网上曝光可能引发二次侵权风险
3. 即使内容属实，公开传播他人信息仍可能构成隐私侵权
4. **「公共利益」不是万能抗辩** —— 公共利益要求你有合理的举报渠道和方式
5. 被举报人确实有违法行为 不等于 你可以公开其个人隐私信息

## 五、「互骂」场景特别提醒

### 核心规则：互骂互赔

| 规则 | 说明 | 参考依据 |
|------|------|---------|
| 双方均构成侵权 | 不存在「正当防卫式的骂回去」 | 北京互联网法院互骂案 [platform_found] |
| 「他先骂的」不构成免责 | 各自对自己的言论负责 | 多案一致 [platform_found] |
| 各自向对方道歉 | 在侵权发生的同一平台/群内 | 北京互联网法院互骂案 [platform_found] |
| 各自赔偿对方 | 律师费互赔 | 福州长乐案：互赔3750元 [platform_found] |
| 精神损害通常不支持 | 双方均有过错，法院认定不构成「严重」 | 多案一致 [platform_found] |
| 占用公共资源可加重 | 在群聊中持续对骂引起他人反感 | 北京互联网法院互骂案 [platform_found] |

### 正确应对对方先骂你的情况

```
对方在网上骂你
  → 截图/录屏保存证据（不要删除，不要回骂）
  → 如在群聊，通知群主/管理员处理
  → 如在平台，使用平台的举报/投诉功能
  → 如涉及严重侮辱/诽谤/隐私泄露
      → 向公证机构申请证据保全公证
      → 通知平台采取删除/屏蔽措施（民法典第1195条）
      → 考虑起诉（名誉权/隐私权/肖像权）
  → 全程不要回骂（回骂=你也侵权）
  → 不要「以牙还牙」公开对方隐私（你也侵权）
```

### 常见错误认知

| 错误认知 | 法律真相 |
|---------|---------|
| 「他先骂我的，我骂回去是正当防卫」 | 不存在「言语正当防卫」，互骂互赔 |
| 「我说的都是事实，所以不违法」 | 「说的是事实」不等于 可以公开他人隐私 |
| 「他先出轨/骗钱，我骂他活该」 | 对方有过错可减责，但不等于你免责 |
| 「我只是转发别人说的」 | 转发也可能承担连带责任 |
| 「我设置仅好友可见，不算公开」 | 共同好友圈中仍可导致社会评价降低 |
| 「群里的人我都不认识，骂了也没事」 | 不特定关系人群 = 公共空间（指导案例143号） |
| 「我匿名发的，查不到我」 | 平台有实名制，法院可调取注册信息 |

## 六、其他特殊场景

### 学生/校园纠纷

| 可以说 | 不可以说 |
|--------|---------|
| 「XX 学校的 XX 课程体验不好」 | 在贴吧发同学的照片+侮辱性评价 |
| 「我觉得学校的 XX 政策不合理」 | 「XX 老师是傻X」（具名侮辱） |
| 基于事实的匿名评价 | 公开同学/老师的个人隐私信息 |

**注意：** 成都中院2023年典型案例：高中学生因社交媒体纠纷导致焦虑、自伤，法院发出人身安全保护令 [platform_found]。

### 恋爱/情感纠纷（非前恋人专属）

**路由提醒：** 如果是前恋人在社交媒体挂人，应路由到 `ex-lover-reputation-case` skill，该 skill 有更精细的赔偿预测模型。

如果是恋爱中/追求中的纠纷：
- 表达感受 = 安全（「我觉得被欺骗了」）
- 公开聊天记录 = 隐私风险
- 公开对方信息 = 高风险
- 侮辱性语言 = 侵权

## 七、「事出有因」减轻元素通用指引

> 本节为所有「对方有过错在先」的场景提供减责评估框架，适用于恋爱纠纷、消费纠纷、职场争议、暴力受害等多种情况。当 SKILL.md 检查 7 识别到对方过错时，加载本节内容。

### 7.1 减轻元素的核心法律逻辑

**民法典第1173条：** 被侵权人对同一损害的发生或者扩大有过错的，可以减轻侵权人的责任 [verified]。

| 法律特征 | 说明 | 裁判依据 |
|---------|------|---------|
| **「事出有因」是普遍减责事由** | 非无端攻击，而是对对方过错行为的反应 | 多案一致 [platform_found] |
| **对方过错不等于你免责** | 减轻赔偿金额，但不让你从「侵权」变成「不侵权」 | 多案一致 [platform_found] |
| **事实陈述有据 = 诽谤不成立** | 诽谤的构成要件是「捏造虚假事实」，事实属实则不构成 | 多案一致 [platform_found] |
| **隐私泄露不受过错减免** | 即使对方是加害方，公开其隐私信息仍构成侵权 | 多案一致 [platform_found] |
| **侮辱性语言需结合语境** | 同一词汇在无端攻击 vs 受害反击语境下评价不同 | 法院考量引发原因 [platform_found] |

### 7.2 对方过错四级评估详表

#### IV级-重大过错（减责至 1/10）

| 过错类型 | 说明 | 典型情形 |
|---------|------|---------|
| 犯罪行为 | 对方行为已构成刑事犯罪 | 诈骗、故意伤害、性侵 |
| 家暴/暴力 | 对受害人实施身体暴力 | 配偶/伴侣/亲属实施殴打 |
| 已婚隐瞒婚姻 | 隐瞒已婚身份与他人建立恋爱关系 | 已婚者以单身身份追求他人 |
| 以恋爱为名的欺诈 | 利用恋爱关系骗取财物 | 编造身份骗钱后消失 |

#### III级-严重过错（减责至 1/5~1/8）

| 过错类型 | 说明 | 典型情形 |
|---------|------|---------|
| 隐瞒已有伴侣 | 已有恋人/伴侣，仍主动追求他人且未告知 | 「脚踏两只船」、让对方不知情成为「第三者」 |
| 系统性欺骗 | 多个关键事项上持续隐瞒/说谎 | 隐瞒婚史、隐瞒与他人关系、虚假承诺 |
| 消费欺诈 | 商家以虚假宣传/假冒伪劣欺骗消费者 | 虚假宣传导致消费者损失 |
| 严重违约 | 合同对方严重违反约定义务 | 收钱后跑路、交付严重不符 |

#### II级-一般过错（减责至 1/3~1/5）

| 过错类型 | 说明 | 典型情形 |
|---------|------|---------|
| 不忠行为 | 出轨一次后坦白 | 感情上的背叛但程度较轻 |
| 服务/商品质量缺陷 | 消费场景中商家有过错 | 产品质量差、服务态度恶劣 |
| 职场不当行为 | 用人单位/同事的不当行为 | 欠薪、职场霸凌 |
| 一般违约 | 合同对方违约但非恶意 | 延迟交付、部分不符 |

#### I级-轻微过错（减责至 1/2）

| 过错类型 | 说明 | 典型情形 |
|---------|------|---------|
| 沟通方式不当 | 没有恶意但处理方式不好 | 态度冷淡、不回消息 |
| 双方均有责任 | 一般性矛盾双方都有过错 | 吵架升级但无根本性过错 |

#### 无过错（不减责）

| 情形 | 说明 |
|------|------|
| 正常分手后因不甘心发帖 | 对方无引发行为 |
| 商家正常经营被恶意差评 | 商家无过错 |
| 单方面误解 | 对方并无不当行为 |

### 7.3 你方证据强度评估详表

| 等级 | 证据类型 | 对诽谤的影响 | 质证时的注意事项 |
|------|---------|-------------|----------------|
| **强** | 对方亲口承认的录音；书面承认；庭审中承认事实 | 诽谤指控**瓦解** | 录音需完整未剪辑，保留原始载体；庭审承认可直接固定 |
| **中** | 聊天记录截图；照片；证人证言；交易记录 | 诽谤指控**基本不成立** | 聊天记录建议做证据保全公证 |
| **弱** | 口头陈述无佐证；间接推断 | 诽谤风险**降低**但仍存在 | 法院可能认定证据不足，建议补强 |
| **无** | 无任何证据 | 诽谤风险**不变** | 避免具体事实指控 |

### 7.4 「承认行为不承认定性」的处理策略

实践中对方常采取的策略：承认客观事实，但否认定性（如「有女朋友但不算出轨」「产品质量问题但不构成欺诈」）。

**法律逻辑：**
- 诽谤的构成要件 = 「捏造虚假事实」
- 对方承认了客观事实 → 你说的不是捏造 → 诽谤不成立
- 定性争议不影响事实真实性，法院可自行认定行为性质

**庭审/质证中：** 固定客观事实即可，不需争论定性。对方说「是，但……」→「是」部分已固定。

### 7.5 不可减免的项目（所有场景通用）

以下行为**不因对方过错而减免**：

| 行为 | 为什么不减免 |
|------|------------|
| 公开对方微信号/手机号 | 隐私侵权独立于对方过错 [platform_found] |
| 公开对方身份证号/住址/工作单位 | 同上 |
| 使用未经同意的照片 | 肖像权侵权独立于对方过错 |
| 威胁性言论 | 威胁行为本身构成侵权 |
| 将纠纷扩展到对方家人 | 无法合理解释 |
| 夸大/类比性指控 | 即使事实属实，夸大类比仍构成诽谤 |

**关键规则：** 对方过错可以**减轻赔偿金额**，但不能让你从「侵权」变成「不侵权」。

### 7.6 各场景安全表达 vs 危险表达

| 你想表达的意思 | 安全表达 | 危险表达 |
|--------------|---------|---------|
| 发现被欺骗 | 「我发现实际情况与对方告知的不符」 | 「这个骗子大家注意」+ 公开对方信息 |
| 感到愤怒/受伤 | 「我感到很受伤，这是我的真实感受」 | 在公共问答下植入对方信息 |
| 想让别人避雷 | 「分享一下我的经历供参考」 | 跨多个平台注册多账号发布 |
| 对方不回应 | 「我一直希望能得到一个回应」 | 「不回应我就让所有人都知道」 |
| 消费体验差 | 「这家店的服务和我的预期差距很大」 | 「这家店老板是人渣」+ 公开手机号 |
| 职场遭遇不公 | 「我在这个公司的劳动体验不好」 | 公开前同事的身份证号/住址 |

### 7.7 诉讼策略建议（被告视角）

1. **不要否认自己发布的内容**（截图证据面前否认更不利）
2. **重点整理证明对方过错的证据**（录音、聊天记录、时间线材料）
3. **质证时攻击对方证据的形式问题**（截图是否经过公证？OCR 是否准确？是否完整？）
4. **提出对方过错减轻赔偿的抗辩**（民法典第1173条）
5. **考虑调解**——对方自身有过错，调解对你方更有利

# 网络言论侵权/网络暴力行为分类框架

> 供 `network-argument-safety-simulator` 的七项检查与相似案例匹配使用。
> 目的：让普通人/网红/自媒体用「我是谁 → 我要挂谁 → 我怎么发」三步定位风险。
> 本框架于 2026-07-08 通过元典 MCP 补充检索后建立，整合权威案例库、指导案例与精选案例。

---

## 一、三维定位法（用户自查入口）

用户回答三个问题即可完成风险初判：

```
第1问：你和对方是什么关系？   → R1-R7（主体关系，决定基础风险档位）
第2问：你打算用什么方式发？   → A1-A12（行为方式，决定民事/行政/刑事）
第3问：发在哪、多少人看到？   → P1-P6（平台场景，决定传播力 & 是否过刑事门槛）
```

三维交叉后，落到「责任层级」速查表（见第六节），即可给出 GREEN/YELLOW/RED 初判。

> 在进入 R/A/P 三问之前，用户通常先有一个直觉：「**我要做什么、为谁做**」。这就是下面的「场景双轴」。

---

## 二、场景双轴分类（第零问：我要做什么、为谁）

> 这是用户自查的**最直觉入口**，比 R/A/P 更靠前。
> 原来的 8 类场景（消费/吃瓜/互挂/情感/公共事务/饭圈/二创/求助）因分类维度不统一而重叠。
> 现统一为**两个正交问题**重组，互斥、不重叠。

### 双轴定义

```
轴1「为谁」：          轴2「发声性质」：
 ① 为自己              a 恢复/保护权益（维权求助）
 ② 为特定他人          b 监督公共事务/保护多数人
 ③ 为不特定多数人/公益  c 表达观点/参与公共话题
                        d 制造内容（创作/玩梗/AI）
                        e 解决私人冲突（宣泄/对抗）
```

### 六大类场景（双轴交叉后去重）

| 编号 | 场景 | 为谁 × 性质 | 法律保护倾向 | 典型行为 | 原8类归属 |
|------|------|-----------|------------|---------|----------|
| **G1** | **维权求助**（为自己恢复权益） | ①×a | 🟢 **最强** | 消费/合同维权、劳动维权、被侵权索赔、家暴/被骗后发声求助、寻亲寻人、被网暴后澄清追责 | 原 S1消费 + S8求助（合并） |
| **G2** | **公益监督/举报吹哨**（为多数人） | ③×b | 🟢 **强** | 业主群监督业委会、食药安全举报、环境污染曝光、公共利益吹哨 | 原 S5公共事务（独立出来） |
| **G3** | **公共话题参与**（表达观点） | ①或②×c | 🟡🔴 灰色 | 热点吃瓜评论、明星塌房评论、跟风转发、粉丝饭圈互动 | 原 S2吃瓜 + S6饭圈（合并） |
| **G4** | **内容创作/玩梗**（制造内容） | ②或①×d | 🟡🔴 新型 | 二创/玩梗/恶搞蹭热点、AI P图丑化、AI合成造谣视频、蹭热点做表情包 | 原 S7二创 |
| **G5** | **私人冲突发声**（宣泄/对抗） | ①×e | 🟡 **弱** | 挂前任/第三者、骂邻居同事、职场爆料、情感纠纷曝光 | 原 S3互挂 + S4情感（合并） |
| **G6** | **代他人发声**（为特定他人） | ②×a或c | 🟡🔴 看动机 | 替朋友出头、转发他人求助、为当事人鸣冤 | 原 S7第三方部分 |

### 关键调整说明（回应"重叠"问题）

1. **维权+求助合并为 G1**：两者本质都是"为自己恢复受损权益"，法律保护倾向一致（最强），强行分成两类是人为割裂。细分靠 G1 内部四个子类（见 `rights-defense-and-whistleblowing.md`）。
2. **公益监督独立为 G2**：你点出的"为自己还是为多数人"是关键分野。G2（为多数人）和 G1（为自己）的保护逻辑不同——G2 侧重"吹哨人保护+不得恶意举报牟利"，G1 侧重"正当维权+不得变敲诈"。
3. **吃瓜+饭圈合并为 G3**：两者都是"参与公共话题、表达观点"，灰色地带一致。
4. **互挂+情感合并为 G5**：两者都是"私人冲突的公开化"，互骂互赔逻辑一致。

### G1 维权求助的四个子类（精细化）

| 子类 | 场景 | 特殊风险点 |
|------|------|-----------|
| **G1a 消费/合同维权** | 差评、避雷、投诉商家 | 守安全线（真实体验+中性语言+不挂老板隐私）；越过线=侵权 |
| **G1b 劳动/职场维权** | 欠薪发声、职场不公曝光 | 围绕劳动权益+公共利益，不侮辱人格、不泄商业秘密 |
| **G1c 人身权益维权求助** | 被侵权索赔、家暴控诉、被骗发声、寻亲寻人 | 双刃剑：自身受害受保护，但事实陈述需证据，不能借维权引导网暴对方 |
| **G1d 被网暴后反向维权** | 被造谣/被开盒后澄清+追责 | 🟢 最安全；但澄清时不能反向造谣侮辱，否则互骂互赔 |

详细指引见 `rights-defense-and-whistleblowing.md`。

### 场景与 R/A/P 的关系

场景（G1-G6）决定**法律保护倾向**和**举证方向**；R1-R7（主体关系）、A1-A12（行为方式）、P1-P6（平台）决定**具体风险等级**。四层叠加：

```
G（场景：为谁×性质）→ 决定保护倾向
  + R（主体关系）   → 决定基础风险档
    + A（行为方式） → 决定民事/行政/刑事
      + P（平台传播）→ 决定是否过门槛
```

## 三、主体关系类型（R1-R7）—— 自查第一问

按「行为人 → 被害人」的身份组合分类，每类风险特征截然不同。

| 编号 | 类型 | 典型场景 | 基础风险 | 核心裁判规则 |
|------|------|---------|---------|------------|
| **R1** | **博主/网红/自媒体 → 素人** | 大V为流量挂普通人、偷拍造谣、AI换脸素人 | 🔴 最高危 | 「随意以普通公众为侵害对象」= 严重危害社会秩序，可自诉转公诉（法发〔2023〕14号） |
| **R2** | **素人 → 明星/公众人物** | 普通人发帖曝明星隐私、P图造谣、跟风黑 | 🔴 高危 | 公众人物容忍义务较高，但**捏造事实/曝光隐私/侮辱**仍侵权；传播量极易过 5000/500 入罪门槛 |
| **R3** | **素人 ↔ 素人（平等互挂）** | 邻居、同事、前任、网友在群/朋友圈互骂 | 🟡 中危 | **「他先骂的」不免责**，互骂互赔；小群也担责 |
| **R4** | **消费者 → 商家** | 差评、避雷帖、投诉帖、曝光黑心商家 | 🟢 相对安全 | 有监督批评权保护，但**越过安全线（侮辱/捏造/无真实交易）= 侵权** |
| **R5** | **商家/企业 → 消费者** | 商家反向挂消费者、曝光买家信息 | 🟡 中危 | 较少见，但曝光消费者个人信息 = 隐私侵权 |
| **R6** | **员工/前员工 → 老板/前公司** | 离职后挂前老板、曝光公司内幕 | 🟡 中危 | 「仅好友可见」不免责，共同好友圈足以降低评价 |
| **R7** | **第三方（非当事人）→ 当事人** | 替朋友出头、蹭热点曝光、误传「第三者」 | 🔴 高危 | **第三人公布他人私事超出言论自由边界**；未经核实转发 = 主观过错 |

### R1-R7 风险档位速判

- **🔴 最高/高危（R1、R2、R7）**：传播力强或主观过错明显，极易触发刑事或高额赔偿
- **🟡 中危（R3、R5、R6）**：以民事为主，但互骂互赔、持续发布会加重
- **🟢 相对安全（R4）**：有法定监督批评权，但必须守住安全线

### 关键区分点

1. **R1（博主挂素人）是当前司法打击重点**。2023 年最高法惩治网暴指导意见（法发〔2023〕14号）明确：「随意以普通公众为侵害对象」是认定「严重危害社会秩序」、自诉转公诉的重要判断因素。
2. **R2（素人挂明星）不要误以为「明星该容忍」**。公众人物容忍义务仅针对**基于公共利益的正当批评**，**捏造事实、曝光隐私、侮辱人格**仍构成侵权。代表案例：杨紫案（(2020)京0491民初14232号）、欧芷晴案（(2020)沪0106民初9756号，赔精神损害5万）。
3. **R7（第三方介入）是隐形高危区**。第三人公布他人私密关系细节超出言论自由边界（重庆钱某案，1.3亿阅读，赔22800）；未经核实转发配照片 = 主观过错（上海奉贤误传第三者案，赔7000含律师费）。

## 四、行为方式类型（A1-A12）—— 自查第二问

同一主体关系下，行为方式决定是民事、行政还是刑事。

| 编号 | 行为类型 | 触发权利/罪名 | 典型措辞/表现 | 严重程度 |
|------|---------|-------------|-------------|---------|
| **A1** | 公然侮辱 | 名誉权 → 治安 → **侮辱罪** | 脏话、贴标签（人渣、骗子、小三、绿茶、PUA渣男、丑紫、硅胶脸、恶臭蛆） | C/D级词汇风险高 |
| **A2** | 捏造事实诽谤 | 名誉权 → **诽谤罪**（浏览≥5000/转发≥500） | 造谣出轨、偷东西、诈骗、买热搜、PUA | 极高危 |
| **A3** | 挂人/人肉 | 隐私权 → **侵犯公民个人信息罪** | 公布姓名、电话、地址、单位、家人信息、身份证号 | 刑事风险突出 |
| **A4** | 未经同意发他人照片/视频 | **肖像权**（民法典1019条） | 偷拍、挂照片、恶搞P图 | 民事为主 |
| **A5** | 曝光隐私 | **隐私权**（民法典1032条） | 私生活、病史、性取向、家庭关系、收入、开房记录 | 民事+可能治安；「说的是事实」≠免责 |
| **A6** | 传播他人私密影像 | **侮辱罪 + 传播淫秽物品罪**（想象竞合从重） | 偷拍、报复性泄露、AI脱衣、换脸淫秽视频 | 极高危，可公诉 |
| **A7** | 转发/转述未核实信息 | 转发不免责，配照片=主观过错 | 「听说」「据传」+ 转发他人爆料 | 视传播量定 |
| **A8** | 小号自导自演 | 主观恶意加重情节 | 大小号一唱一和、自问自答 | 加重赔偿 |
| **A9** | 持续性骚扰 | 加重情节 + 可能从业禁止 | 连发40条、骂一年半、每日直播挂人 | 高额赔偿 |
| **A10** | 煽动/号召网暴 | **寻衅滋事罪**风险 | @明星、引导人肉、号召转发、起哄闹事 | 极高危 |
| **A11** | AI 用于侮辱诽谤（AI P图/AI脱衣/合成造谣） | 名誉权 → **侮辱罪/诽谤罪** | AI脱衣、把人脸P到色情图、AI生成虚假不雅照、深度合成造谣视频、AI恶搞丑化人格 | 新型高频，属侮辱诽谤范畴 |
| **A12** | 直播辱骂/挂人 | 侮辱罪可公诉 + 从业禁止 | 实时直播、观看过千、持续数十次挂人 | 薛某琴案（判6个月+3年禁业） |

### 行为方式 × 责任层级映射

- **仅民事**：A4（肖像，如未经同意发他人照片）、A5（隐私，轻）、A7（转发，量小）
- **民事 + 行政**：A1（侮辱，未达罪量）、A2（诽谤，量小）、A3（人肉，情节轻）
- **刑事**：A2（量达标）、A3（情节严重）、A6（私密影像）、A10（寻衅滋事）、A11（AI 用于侮辱诽谤，情节严重）、A12（直播，严重）

## 五、平台/场景维度（P1-P6）—— 自查第三问

影响「公共空间属性」认定与传播力评估，直接关系是否过刑事门槛。

| 编号 | 平台 | 公共空间属性 | 传播力档位 | 关键规则 |
|------|------|------------|----------|---------|
| **P1** | **朋友圈** | 半公开（共同好友圈） | T2-T3 | 「仅好友可见」**不免责**，共同好友圈足以降低评价（郑州前同事案、临沂范某某案） |
| **P2** | **微信群** | 视成员构成 | T2-T4 | 非特定关系人群 = **公共空间**（指导案例143号确立）；村集体群、业主群、老乡群均认定 |
| **P3** | **微博/公众平台** | 完全公开 | T4-T5 | 传播力最强，最易过刑事门槛；@明星、上热搜 = 加重 |
| **P4** | **小红书/抖音/快手** | 完全公开 | T3-T5 | 避雷帖、挂人视频、AI模板高发；算法推荐放大传播 |
| **P5** | **直播间** | 实时公开 | T3-T4 | 观看过千 = 严重情节；可附从业禁止 |
| **P6** | **评论区/弹幕/私信** | 半公开/点对点 | T1-T2 | 易被忽视，但同样担责；私信威胁可构成治安 |

### 平台传播力与刑事门槛对照

刑事诽谤罪门槛（法释〔2013〕21号第2条）：
- 同一诽谤信息实际被**点击、浏览 ≥ 5000次**
- 或被**转发 ≥ 500次**

各平台典型风险：
- **P3 微博**：粉丝量大、热搜效应，几小时即可过门槛（吴某某案 4.7亿阅读）
- **P4 抖音/小红书**：算法推荐，冷启动也能快速过门槛
- **P1 朋友圈**：共同好友数百人即可达「降低评价」标准，但难达刑事门槛（除非被截图外传）
- **P2 微信群**：500人大群 + 截图外传 = 可过门槛

## 六、责任三层级速查表

| 层级 | 触发条件 | 法律依据 | 后果 |
|------|---------|---------|------|
| **民事** | 侮辱/诽谤/挂人/曝光隐私/肖像/声音侵权 | 民法典 1024/1032/1019/1019-1023/1194-1197 | 删除+道歉+赔偿（500-5万+） |
| **行政** | 公然侮辱/捏造诽谤/威胁/散布隐私 | **治安管理处罚法第50条**（2025修订，2026.1.1起罚款上限**1000元**） | 拘留5-10天+罚款≤1000元 |
| **刑事** | 浏览≥5000/转发≥500，或造成自杀/精神失常，或「严重危害社会秩序」 | 刑法 246条（侮辱/诽谤，3年以下）、253条之一（侵犯公民个人信息，7年以下）、293条（寻衅滋事，5年以下） | 有期徒刑+罚金+缓刑 |

> ⚠️ **时效性更新（2026-07-08）**：治安管理处罚法已于 2025 年修订，原**第42条**对应内容调整至**第50条**，罚款上限从 **500元 提升至 1000元**，新增「滋扰、纠缠、跟踪」可裁定禁止接触。原案例库中引用「第42条、500元」的地方需更新。

| 组合 | 描述 | 典型案例 |
|------|------|---------|
| **R1 + A2 + P3/P4** | 博主为流量挂素人 + 造谣 + 微博/短视频 | 吴某某造谣案（4.7亿阅读，判1年）；郎某何某偷拍取快递女子案（自诉转公诉，判1缓2） |
| **R1 + A6** | 传播可识别身份的他人私密影像 | 李某侮辱案（(2023)苏0591刑初703号，想象竞合定侮辱罪，判10个月） |

| **R7 + A5/A7** | 第三方介入 + 曝光隐私/未核实转发 | 重庆钱某案（赔22800）；上海奉贤误传第三者案（赔7000） |
| **R2 + A1/A2 + P3** | 素人挂明星 + 侮辱诽谤 + 微博 | 杨紫案（书面道歉+精神赔偿）；网红照妖镜案（(2020)沪0107民初1518号，赔2000+律师费5000） |
| **A11 AI用于侮辱诽谤** | AI脱衣/P图丑化/合成虚假不雅照/深度合成造谣视频 | AI脱衣可构成侮辱罪（参考李某侮辱案A6类，AI生成不雅内容传播贬损人格）；合成造谣视频过浏览/转发门槛可定诽谤罪 |

## 八、安全线（GREEN 档位参考）

满足以下全部条件，通常为 GREEN：

1. **无 C/D 级侮辱词汇**（参考 `legal-boundary-test.md` A/B/C/D 分级）
2. **事实陈述有证据支撑**，或明确标注为主观评价（「我认为」「在我看来」）
3. **无个人可识别信息**（姓名、电话、地址、单位、家人、身份证、照片）
4. **无未经同意的肖像/声音使用**
5. **传播可控**（未上热搜、未被大V转发、未跨平台）
6. **未达刑事门槛**（浏览<5000 且 转发<500）
7. **无煽动、号召、人肉引导**

### 各主体关系的安全线补充

- **R4 消费者安全线**：真实体验 + 中性语言 + 商家公开信息 + 不挂老板个人隐私
- **R6 职场安全线**：围绕劳动权益/公共利益，不进行人格侮辱，不泄露商业秘密
- **R7 第三方安全线**：不公布当事人私密细节，转发必须核实，不配当事人照片
